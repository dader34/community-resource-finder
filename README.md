# Community Resource Finder
EVCC Python Final project. A simple menu based program to help affected communities to access relevant helpful information.

*Project by Danner Baumgartner, Fahad Razzaq Baloch, Fawad Razzaq Baloch, and Cy Reinier. Documentation written by Cy Reinier.*

------------

This documentation will teach you how to use the community resource finder, including how to navigate the menus and what each category has.

**Landing Page**

This is the first menu you see when you start up the program. I'll be going through the sections individually.

``1. Browse by Category``
As it says on the tin. Lets you browse by the different categories: Food, Free Clinics, Legal Aid, Shelters, and ESL (English as a Second Language).

For example, if you're looking for legal advice, you can first Browse by Category, and then search by Legal Aid. The program will come up with resources that can help.

If you want to know what each category does specifically, please scroll down to the next section titled **Categories**.

``2. Search by Name``
Lets you search by name; for if you have a resource or topic in mind and want to find it through the program. 

For example, entering the term 'Gospel' brings up two resources from the Everett Gospel Mission; their Clinic, and their Women & Children Shelter.

``3. Filter by Language``
Lets you filter by 7 different languages. In descending order: English, Spanish, Vietnamese, Tagalog, Korean, Russian, German, Arabic, and Ukrainian.

``4. View All Resources``
Lets you view all 48 resources at once.

``5. Language Coverage Stats``
Shows the statistics for how many resources cover what languages.

``6. Exit Program``
Exits the program.

-----

**Categories**

This finder sorts it's resources by **category**. They are as follows:

``1. Food``
Contains food banks and food pantries.

``2. Free Clinics``
Contains clinics that will offer some or all services for free. Includes a wide range of healthcare options, including Planned Parenthood and Behavioural options.

``3. Legal Aid``
Contains legal resources and justice programs. Includes help offices, volunteer services, and public defender programs.

``4. Shelters``
Contains places for temporary housing and shelter. Includes youth shelters, shelters for those who are experiencing domestic violence, and shelters for families.

``5. ESL``
Contains classes and programs for learning English as a second language. For all ages and offered in multiple settings for convenience.
